# 单端子设备端子四边切换设计

## 目标

允许用户在编辑模式下直接拖动单端子设备的端子，并将端子切换到设备上、下、左、右四个边中点之一。该操作不能破坏现有的单击端子建立连接线功能。

## 交互规则

- 仅非母线且恰好包含一个端子的设备支持该操作。
- 鼠标在端子上按下并直接松开时，继续进入现有的建立连接线流程。
- 鼠标按下后移动超过现有拖动阈值时，切换为端子位置调整，不再启动连接线。
- 调整过程中，端子只能吸附到上、下、左、右四个边中点，不允许停留在边上的任意位置。
- 目标边按照鼠标位置与四个候选边中点的距离决定。
- 设备旋转或镜像后，候选点判断仍以屏幕中的实际方向为准，保存的锚点继续使用设备本地坐标。
- 多端子设备、母线、可变线路设备和浏览模式保持现有行为。

## 实现方案

复用现有的 `TerminalPressState`、`handlePointerMove`、`finishTerminalPress` 和 `patchSingleTerminalAnchorFromPoint` 链路。

端子按下时不再立即启动连接，而是记录一次待判定的端子按压状态并捕获指针。后续行为由移动距离决定：

1. 未超过阈值：松开时调用 `startConnectFromTerminal`。
2. 超过阈值：调用 `patchSingleTerminalAnchorFromPoint`，通过 `snapSingleTerminalAnchorToNearestSide` 选择最近的四边中点。
3. 移动过程中实时更新端子锚点及相关连接线路由。
4. 松开时提交最终位置并清理临时交互状态。

已有连接目标选择、线路重接和可变线路放置分支优先级保持不变；只有“当前没有正在进行的连接或重接”时，单端子设备才进入待判定按压状态。

## 数据与撤销

- 最终位置写入目标端子的 `anchor` 字段，取值限定为 `{ x: 0, y: -0.5 }`、`{ x: 0.5, y: 0 }`、`{ x: 0, y: 0.5 }`、`{ x: -0.5, y: 0 }`。
- 第一次实际切换位置时创建一个撤销快照；同一次拖动后续更新不重复创建。
- 相关连接线沿用现有冻结端点、保持线路形状和脏路由标记机制。
- 没有发生位置变化时，不写入节点、不增加撤销记录，也不标记模型为已修改。

## 异常与边界情况

- 指针捕获失败时保持现有容错，不中断页面交互。
- 拖动过程中设备被删除或不再满足单端子条件时，停止位置更新并在松开时清理状态。
- 鼠标位于两个候选方向等距位置时，沿用候选点稳定顺序，避免拖动过程中随机跳动。
- 已连接设备切换端子方向时，所有与该端子关联的连接线同步更新。

## 验证

- 单击单端子设备端子仍能启动连接。
- 拖动超过阈值不会启动连接，而会设置端子按压状态并切换锚点。
- 四个方向均能正确吸附。
- 旋转和镜像设备的方向判断正确。
- 多端子设备和母线行为不变。
- 连接线路由随端子切换更新。
- 撤销一次即可恢复拖动前的端子位置及线路状态。
- 运行端子锚点定向测试、相关画布交互测试和生产构建。
